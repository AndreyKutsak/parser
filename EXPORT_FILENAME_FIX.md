# Виправлення Назв Файлів Експорту

## 🐛 Проблема

При експорті даних створювалися некоректні назви файлів з підкресленнями замість нормальних назв:

- `_________ _____________ __ __________ ________.json`
- `_________ _____________ __ __________ ________.csv`
- `_________ _____________ __ __________ ________.xlsx`

## 🔍 Причина

Функція `sanitize()` в `export.controller.js` замінювала **всі не-ASCII символи** на підкреслення, включаючи українські літери (кирилицю).

**Стара функція:**

```javascript
const sanitize = (name) => name.replace(/[^a-zA-Z0-9_\- ]/g, "_").slice(0, 50);
```

Це призводило до того, що українські назви завдань типу "Категорія електротовари та компоненти ЗАПЧАСТИ" перетворювалися на "****\_**** ******\_****** ** **\_\_\_\_**** **\_\_\_\_**".

## ✅ Рішення

### 1. Покращена функція sanitize

**Нова функція:**

```javascript
const sanitize = (name) => {
  // Allow Ukrainian Cyrillic, Latin letters, numbers, spaces, hyphens, underscores
  const clean = name
    .replace(/[^а-яіїєґА-ЯІЇЄҐa-zA-Z0-9\s\-_]/g, "_") // Replace invalid chars with _
    .replace(/_+/g, "_") // Replace multiple _ with single _
    .replace(/^_|_$/g, "") // Remove leading/trailing _
    .slice(0, 40); // Limit length

  // Add timestamp for uniqueness
  const timestamp = new Date().toISOString().slice(0, 19).replace(/[:-]/g, "");
  return `${clean}_${timestamp}`;
};
```

**Що покращено:**

- ✅ Зберігає українські символи (кирилицю)
- ✅ Додає timestamp для унікальності файлів
- ✅ Обмежує довжину до 40 символів + timestamp
- ✅ Прибирає зайві підкреслення

### 2. Додавання runId до назви файлу

Коли експортуються дані з конкретного запуску (runId), додається ідентифікатор запуску:

```javascript
const filename = req.query.runId
  ? `${sanitize(task.name)}_run_${req.query.runId.slice(-8)}.json`
  : `${sanitize(task.name)}.json`;
```

**Приклади нових назв файлів:**

- `Категорія електротовари та компоненти ЗАПЧАСТИ_20260420T064828.json`
- `Категорія електротовари та компоненти ЗАПЧАСТИ_run_a1b2c3d4.json`
- `Test Task_20260420T064828.xlsx`

## 🚀 Переваги

1. **Читабельність:** Назви файлів тепер зрозумілі та містять українські символи
2. **Унікальність:** Timestamp гарантує, що файли не перезаписують один одного
3. **Ідентифікація:** runId допомагає ідентифікувати дані з конкретного запуску
4. **Сумісність:** Файли сумісні з різними операційними системами
