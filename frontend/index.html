Майстер налаштування

                  

                    Простий режим приховує технічні вкладки. Розширений режим
                    відкриває весь функціонал для складних сценаріїв.
                  

                

                

                  
                  
                

              


              

                
                
                
              


              

                

                  1. Заповніть назву та URL сторінки.
                

                

                  2. На вкладці "Селектори" натисніть "Вибрати".
                

                

                  3. Додайте поля, які треба зберігати.
                

              

            


            

              

                
                
              

              

                
                
              

            

            

              
              
            

            

              

                
                
              

              

                
                
              

            

            

              
              
              

                JSON-об'єкт, рядок form-encoded або довільний текст — залежно
                від обраного формату
              

            

          


          
          

            

              

                Список запитів
                

                  Кожен запит має власний URL, метод і тіло. Використовується
                  замість єдиного URL на вкладці «Основне».
                

              

              
            

            

            

              Якщо список порожній — використовується URL і метод з вкладки
              «Основне».

              Для кожного запиту можна вказати власні селектори, або залишити
              порожніми — тоді використовуватимуться загальні з вкладки
              «Селектори».
            

          


          
          

            

              
              

                
                
                
              

              

                CSS-селектор, що відповідає кожному рядку/картці/елементу у
                списку
              

            


            

              
              
              

                Назва поля (з таблиці нижче), яке унікально ідентифікує товар.
                При повторному парсингу — порівнює значення всіх monitored полів
                з попереднім запуском і зберігає зміни.
              

            


            

              

                Поля для витягування
                
              

              

                Назва поляCSS селекторАтрибутТрансформаціяМонітор
              

              

            

            

              Атрибут: залиште порожнім для тексту, або вкажіть
              src, href,
              data-price тощо.

              Трансформація: trim, number,
              lowercase, regex:(\d+):1
            

          


          
          

            

              
            

            

              

                
                
              

              

                
                
              

            

            

              

                
                
              

              

                
                
              

            

            

              
              
            

          


          
          

            

              
            

            

              
              
              
              

                Оберіть простий варіант, і поле cron заповниться автоматично.
                Якщо хочете точний розклад, оберіть «Ввести cron самостійно».
              

            

            

              
              
              

                Формат:
                хвилини години день-місяця місяць день-тижня.
                

                Приклади: */1 * * * * — кожну хвилину,
                0 */6 * * * — кожні 6 годин,
                0 9 * * 1-5 — будні о 9:00,
                0 0 * * * — щодня опівночі.
                

                /1 означає «кожен 1-ий крок» в полі. Тобто
                */1 = «кожний».
              

            

          


          
          

            

              
              
              

                Парсер зайде на кожне таке посилання і зберігатиме поля разом із
                записом списку.
              

            

            

              

                Поля зі сторінки деталей
                
              

              

                Назва поляCSS селекторАтрибутТрансформація
              

              

            


            
            

            

              
              

                Підзадача буде повторно парсити сторінку деталей через заданий
                інтервал і зберігати історію змін.
              

            

            

              

                
                
              

              

                
                
              

            

          


          
          

            

              

                
                
              

              

                
                
              

              

                
                
              

            

            

              
            

            

              
              

                Увімкніть якщо сайт повертає JSON тільки на AJAX-запити
              

            

            

              
              
              

                Вкажіть назву поля в JSON-відповіді, яке містить HTML з товарами
              

            

            

              
              
              

                Крапковий шлях до масиву об'єктів у JSON-відповіді. Після цього
                селектор елемента = .json-item, поля — за назвою
                класу: .name, .brand_name,
                .url і т.д.
              

            

            
            

            

              
              

                Після парсингу кожної сторінки — знаходить всі посилання,
                відкриває їх і парсить так само, рекурсивно.
              

            

            

              

                
                
                

                  Для кожного спарсеного запису підставляє
                  {{назва_поля}} і відкриває побудований URL.

                  Якщо вказано — CSS-селектор посилань ігнорується.
                

              

              

                
                
                

                  Крапковий шлях до масиву в JSON-відповіді crawled-сторінки.
                  Поля масиву доступні в шаблоні наступного рівня через
                  {{назва}}.
                

              

              

                

                  
                  
                

                

                  
                  
                

                

                  
                  
                  

                    Незалежно від «Макс. сторінок» на вкладці «Основне»
                  

                

              

              

                
              

            


            
            

              
              
              
Cookies з вибраної авторизації автоматично додаються до запитів

            


            

              
            


            
            

            

              
              

                Коли парсер знайде новий або змінений контент, відправить дані
                на зовнішній webhook URL.
              

            

            

              

                
                
                

                  URL-адресу вебхука для отримання JSON-даних з новими
                  результатами парсингу.
                

              

              

                
                
              

              

                
                
                

                  JSON-об'єкт з додатковими HTTP-заголовками для запиту вебхука.
                

              

            

          

        

        

          
          
        

      

    


    
    

      

        

          Імпорт проксі
          
        

        

          

            
            
            

              Підтримувані формати: host:port,
              host:port:user:pass,
              protocol://user:pass@host:port

                "Створити завдання"
              
    2. 
              
  2. 
                Налаштуйте URL: Введіть адресу веб-сайту для
                парсингу
              
    3. 
              
  3. 
                Оберіть селектори: Використовуйте візуальний
                селектор або введіть CSS селектори вручну
              
    4. 
              
  4.

                налаштуйте розклад
              
    5. 
              
  5.

                містить витягнуті дані
              
    6. 
            


            
🎯 Візуальний селектор

            
Для легкого вибору елементів на сторінці:

            
    
              
  1. Натисніть "🎯 Вибрати" поруч із полем селектора
    2. 
              
  2. Введіть URL цільового сайту
    3. 
              
  3. Наведіть курсор на елемент — він підсвітиться
    4. 
              
  4. Клікніть для вибору елемента
    5. 
              
  5. Селектор автоматично згенерується
    6.
