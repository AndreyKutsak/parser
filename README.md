# Web Parser Pro

Платформа для веб-парсингу з візуальним вибором селекторів, розкладом запусків, експортом результатів і підтримкою проксі.

## Що покращено

- Спрощено архітектуру сервера: Express-конфігурація винесена з `src/app.js` у модулі `src/server/*`.
- Додано більш дружній інтерфейс: швидкий старт, простий режим створення задачі, мобільне меню.
- Оновлено документацію: окремо для користувачів і окремо для розробників.

## Швидкий старт

### Локально

```bash
npm install
npm run dev
```

Після запуску відкрийте:

- UI: [http://localhost:3000](http://localhost:3000)
- API Docs: [http://localhost:3000/api-docs](http://localhost:3000/api-docs)

## Основні можливості

- Статичний і динамічний парсинг
- Візуальний селектор елементів
- Пагінація, розклад, підзадачі
- Моніторинг змін по ключових полях
- Ротація проксі
- Експорт у JSON, CSV, Excel

## Структура проєкту

```text
src/
  api/          REST API, контролери, маршрути, валідація
  core/         бізнес-логіка парсингу, розкладу, експорту, підзадач
  db/           моделі та підключення до MongoDB
  queue/        черга BullMQ і worker
  server/       складання Express-додатка та proxy для visual selector
  utils/        логування та допоміжні утиліти

frontend/
  index.html
  css/styles.css
  js/api.js
  js/app.js
  js/selector.js
  js/user-friendly.js
```

## Для кого цей проєкт

- Для звичайного користувача, який хоче зібрати товари, новини або каталоги без коду
- Для аналітика, який хоче запускати парсинг за розкладом
- Для розробника, який хоче інтегрувати парсер через REST API
