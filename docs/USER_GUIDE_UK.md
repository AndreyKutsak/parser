# Керівництво користувача

## 1. Перший запуск

1. Відкрийте застосунок у браузері.
2. Зареєструйтесь або увійдіть.
3. На головному екрані перейдіть до створення нової задачі.

## 2. Як створити просту задачу

1. Натисніть `Створити просту задачу`.
2. Введіть:
   - назву задачі
   - URL сторінки
   - тип рушія: `Статичний` або `Динамічний`
3. Перейдіть у вкладку `Селектори`.
4. Натисніть `Вибрати`, потім клікніть по елементу на сайті.
5. Додайте поля, які треба зберігати:
   - назва
   - ціна
   - посилання
   - зображення
6. Натисніть `Зберегти задачу`.

## 3. Коли який режим обирати

### Простий режим

Підходить, якщо вам потрібно:

- швидко зібрати каталог товарів
- спарсити список новин
- отримати базові дані без складних запитів

### Розширений режим

Потрібен, якщо ви використовуєте:

- кілька HTTP-запитів
- парсинг сторінок деталей
- webhook-сповіщення
- рекурсивний обхід
- складні JSON API

## 4. Як працюють основні вкладки

### Основне

- Назва задачі
- URL сторінки
- Метод `GET` або `POST`
- Тіло запиту для `POST`

### Селектори

- Селектор картки або рядка
- Поля для витягування
- Вибір елемента через візуальний селектор

### Пагінація

Використовуйте, якщо дані розбиті на кілька сторінок.

Доступні режими:

- кнопка `Наступна`
- шаблон URL з `{page}`
- нескінченний скрол

### Розклад

Дозволяє запускати задачу автоматично:

- щогодини
- щодня
- у будні
- за власним cron-виразом

### Деталі

Потрібно, якщо треба перейти з картки в окрему сторінку товару або статті та витягнути додаткові поля.

### Додатково

Тут зібрані технічні параметри:

- timeout
- retries
- anti-bot
- проксі
- webhook
- рекурсивний обхід

## 5. Робота з результатами

У розділі `Результати` можна:

- переглядати зібрані записи
- шукати по тексту
- бачити зміни між запусками
- експортувати дані

Формати експорту:

- JSON
- CSV
- Excel
- TXT, якщо ця функція доступна для вашої задачі

## 6. Робота з проксі

У розділі `Проксі` можна:

- додавати нові проксі
- імпортувати списком
- перевіряти доступність
- використовувати ротацію

Використовуйте проксі, якщо сайт блокує часті запити або має обмеження по IP.

## 7. Типові сценарії

### Каталог товарів

- рушій: `Статичний`
- контейнер: `.product-card`
- поля: `title`, `price`, `image`, `link`

### Новини

- рушій: `Статичний`
- контейнер: `article`
- поля: `title`, `date`, `summary`, `link`

### JS-сайт

- рушій: `Динамічний`
- дочекайтесь повного рендеру сторінки через Puppeteer

## 8. Поради для нетехнічного користувача

- Починайте з простого режиму.
- Не додавайте всі опції одразу.
- Спочатку перевірте 2-3 поля на одній сторінці.
- Якщо дані не знаходяться, спробуйте інший контейнер елемента.
- Якщо сайт динамічний, перемкніть рушій на `Динамічний`.

## 9. Якщо щось не працює

- Перевірте, чи відкривається URL у браузері.
- Переконайтесь, що селектор вказує саме на повторюваний елемент.
- Для `POST` перевірте формат тіла запиту.
- Для великих сайтів збільшіть timeout.
- Якщо сайт блокує запити, увімкніть anti-bot або проксі.
