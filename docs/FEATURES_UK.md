# Опис функцій

## Візуальний селектор

Дає змогу натиснути на елемент сторінки та автоматично отримати CSS-селектор.

Корисно для:

- карток товарів
- заголовків
- цін
- посилань

## Автоскан полів

Після вибору контейнера можна спробувати автоматично знайти типові поля:

- назва
- ціна
- опис
- посилання
- картинка

## Моніторинг змін

Якщо задати `ключове поле` та позначити деякі поля як ті, що треба моніторити, система зможе визначати:

- нові записи
- змінені значення
- історію змін

## Кілька HTTP-запитів

Функція для складних сценаріїв, коли одна задача має пройти по кількох endpoint-ах або сторінках API.

## Детальні сторінки

Дозволяє:

- взяти URL зі списку
- перейти на сторінку деталей
- дістати додаткові поля

## Підзадачі

Автоматично створюють регулярні перевірки для сторінок деталей.

Підходить для:

- моніторингу наявності
- контролю зміни ціни
- відстеження стану картки товару

## Рекурсивний обхід

Після обробки сторінки система може перейти за знайденими посиланнями й продовжити парсинг.

Використовуйте обережно, бо це значно збільшує навантаження.

## Webhook-сповіщення

Коли з'являється новий або змінений запис, система може надіслати повідомлення на зовнішній endpoint.

## Експорт

Підтримувані формати:

- `json`
- `csv`
- `excel`
- `txt` для окремих сценаріїв

## Аналітика

Показує:

- кількість записів
- активні задачі
- чергу
- результати запусків
